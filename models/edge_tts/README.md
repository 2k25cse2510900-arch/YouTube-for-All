# Microsoft Edge TTS Integration

## Overview
- **Engine**: Microsoft Edge Neural Text-to-Speech
- **Library**: `edge-tts` (LGPLv3)
- **Cost**: 100% Free / Zero API key required
- **Multi-lingual Support**: Full support for Hindi, Hinglish, Indian English, American English, and 70+ languages.

## Recommended Voices
- `hi-IN-MadhurNeural`: Expressive, warm Indian Hindi male voice.
- `hi-IN-SwaraNeural`: Clear, pedagogical Indian Hindi female voice.
- `en-IN-NeerjaNeural`: Indian English conversational female voice.
- `en-IN-PrabhatNeural`: Indian English documentary male voice.

## Features
- Dynamic word boundary timestamp tracking for subtitles.
- SSML prosody rate, pitch, and contour modulation.
- Integration with `HinglishTextProcessor` and `NativeHindiTextProcessor`.
