# Sarvam AI Bulbul Integration

## Overview
- **Provider**: Sarvam AI
- **Engine**: Bulbul TTS (`bulbul:v1`)
- **Focus**: High-fidelity Indic speech synthesis (Hindi, Tamil, Telugu, Kannada, Bengali, etc.)
- **License**: Commercial / Developer API terms

## Configuration
```env
SARVAM_API_KEY=your_sarvam_api_key_here
SARVAM_VOICE_MODEL=bulbul:v1
SARVAM_DEFAULT_SPEAKER=shubh
```
